# IMAGE GUIDE

## Ortaq yer tutucular

Proyektin şəkil strukturu aşağıdakı kimi qurulub:

- `assets/images/placeholder/AQSIN BABAYEV/portret.png` — portret yeri
- `assets/images/placeholder/scene-placeholder.svg` — həyat sahnələri üçün yer
- `assets/images/placeholder/media-placeholder.svg` — media sahəsi
- `assets/images/placeholder/academic-placeholder.svg` — akademik materiallar
- `assets/images/placeholder/research-placeholder.svg` — araşdırma sahələri
- `assets/images/placeholder/archive-placeholder.svg` — arxiv materialı

## Şəkil əlavə etmə

1. Məqsədə uyğun qovluq yaradın.
2. Fərqli ölçülü şəkili buraya əlavə edin.
3. `assets/js/site-data.js` içərisində `gallery` siyahısına yeni element əlavə edin.
4. `alt` və `title` dəyərlərini düzgün təyin edin.

## Şəkil dəyişmə qaydası

- `src` yolunu dəyişdirin.
- `title`, `category`, `alt` dəyərlərini aktual məlumatla yeniləyin.
- İstənilən qovluq adını qalıq kodu pozmadan istifadə edin.

## Xahiş

Gələcək mərhələdə real foto, portret, arxiv və kitab üz qabığı faylları yerləşdirildikdən sonra `site-data.js` və `IMAGE-GUIDE.md` yenilənəcəkdir.
